### 1. 認証フローテスト

**テスト目的**: Google OAuth認証の動作確認

**手順**:
```
1. アプリを起動
2. ログイン画面で「Googleでログイン」ボタンをタップ
3. Google認証画面が表示されることを確認
4. Googleアカウントを選択してログイン
5. ログイン成功後、メインScreen画面に遷移することを確認
```

**期待結果**:
- [ ] Google OAuth認証画面が表示される
- [ ] ログイン成功後にメイン画面へ遷移
- [ ] `authService.isAuthenticated` が `true` になる
- [ ] `authService.userId` にUUIDが設定される

**確認コマンド**（デバッグ時）:
```dart
print('認証状態: ${authService.isAuthenticated}');
print('ユーザーID: ${authService.userId}');
```

### 2. データCRUDテスト

#### 2.1 プロフィール作成

**手順**:
```
1. 初回ログイン後、名前入力画面が表示
2. 名前を入力（例: 'ママ'）
3. 「登録」ボタンをタップ
4. プロフィール作成成功
```

**期待結果**:
- [ ] プロフィール作成が成功する
- [ ] Supabase `profiles` テーブルにデータが登録される
- [ ] エラーが発生しない

**確認SQL**:
```sql
SELECT * FROM profiles WHERE id = 'USER_UUID';
```

#### 2.2 家族作成

**手順**:
```
1. ホーム画面で「家族を作成」ボタンをタップ

3. 「作成」ボタンをタップ
4. 家族作成成功、family_idが返される
```

**期待結果**:
- [ ] 家族作成が成功し、family_idが返される
- [ ] `families` テーブルにデータが登録される
- [ ] `family_members` テーブルに自分が追加される


### 3. リアルタイム同期テスト

**テスト目的**: WebSocketによるリアルタイム同期の確認

**前提条件**:
- 2台の端末（またはエミュレータ）を用意
- 同じ家族に参加

**手順**:
```
1. 端末Aでリスト画面を開く
2. 端末Bでも同じリスト画面を開く
3. 端末Aでアイテムを追加
4. 端末Bに自動的にアイテムが表示されることを確認
5. 端末Bでアイテムを完了
6. 端末Aでアイテムが完了状態になることを確認
```

**期待結果**:
- [ ] 端末Aの変更が端末Bに即座に反映される（< 1秒）
- [ ] 端末Bの変更が端末Aに即座に反映される（< 1秒）
- [ ] コールバック関数が正しく呼ばれる
- [ ] エラーが発生しない

**デバッグ確認**:
```dart
realtimeService.subscribeToList(listId, (payload) {
  print('リアルタイム変更: ${payload['eventType']}');
  print('新しいデータ: ${payload['new']}');
});
```
