## 📝 **必須修正事項（2点）**

### 1. **roleカラムの削除**

```sql
-- 現在（修正前）
CREATE TABLE users (
    role VARCHAR(10) NOT NULL CHECK (role IN ('parent', 'child')),  -- ❌ 削除
);

-- 修正後
-- usersテーブル自体を削除し、profilesテーブルに置き換え
CREATE TABLE profiles (
    id UUID PRIMARY KEY REFERENCES auth.users(id),
    name VARCHAR(50) NOT NULL,
    created_at TIMESTAMPTZ DEFAULT NOW()
);
```

**理由**: Option 1（完全フラット）決定により親子区別不要

### 2. **RLSポリシーの簡素化**

```sql
-- 現在（複雑）
CREATE POLICY families_policy ON families
    FOR ALL TO authenticated
    USING (
        id IN (
            SELECT family_id FROM family_members
            WHERE user_id IN (SELECT id FROM users WHERE auth_id = auth.uid())
        )
    );

-- 修正後（シンプル）
CREATE POLICY "authenticated_users_full_access" ON families
    FOR ALL TO authenticated 
    USING (
        EXISTS (
            SELECT 1 FROM family_members 
            WHERE family_id = families.id 
            AND user_id = auth.uid()
        )
    );
```

**理由**: ネストが深すぎて複雑。シンプルなEXISTSで十分
